Cowboy `2.18.0`, Cowlib `2.19.0`, Gun `2.5.0`
and Ranch `2.2.1` have been released.

They contain a number of defense-in-depth and
security hardening improvements so all users
are encouraged to upgrade.

The
https://ninenines.eu/docs/en/cowboy/2.17/guide/security_checklist/[security checklist]
has received a few tweaks as well.

Expect a few more security oriented releases in the
near future. They will address increased threats from
AI agents usage. Please refer to the companion post
https://ninenines.eu/articles/security-strategy[explaining the security strategy]
for more details.

A detailed list of changes can be found in the
https://ninenines.eu/docs/en/cowboy/2.18/guide/migrating_from_2.17/[Cowboy migration guide], the
https://ninenines.eu/docs/en/gun/2.5/guide/migrating_from_2.4/[Gun migration guide] and the
https://ninenines.eu/docs/en/ranch/2.2/guide/migrating_from_2.2/[Ranch migration guide].

You can donate to these projects via
https://github.com/sponsors/essen[GitHub Sponsors].

As usual, feedback is appreciated, and issues or
questions should be sent via Github tickets or
discussions. We also have a Discord server.
https://discord.gg/x25nNq2fFE[Join Erlang OSS Discord now!]
